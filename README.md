# 🏨 Hotel Booking System (Backend)

## 📌 Описание проекта

Hotel Booking System — это backend-сервис для управления бронированием номеров в отеле.  
Проект разрабатывается как **pet project** на платформе **C# / .NET** для практики современной backend-разработки.

Система предоставляет REST API для:
- поиска доступных номеров;
- управления бронированиями;
- аутентификации пользователей;
- обработки платежей;
- администрирования отелей.

---

## 🎯 Цели проекта

- Создать полнофункциональную backend-платформу для автоматизации бронирования отелей
- Обеспечить стабильную и безопасную обработку пользовательских бронирований
- Реализовать централизованное управление номерным фондом и ценами
- Повысить эффективность работы администраторов и менеджеров отеля
- Обеспечить интеграцию с платёжными и уведомительными сервисами
- Снизить количество ручных операций при работе с клиентами
- Обеспечить масштабируемость системы для подключения новых отелей
- Подготовить архитектуру для возможного выхода в коммерческую эксплуатацию
- Обеспечить высокую доступность и отказоустойчивость сервиса
- Создать основу для развития мобильных и партнёрских приложений
